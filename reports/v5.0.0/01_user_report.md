# ClawsJoy v5.0.0 - 您的私人管家

## 您好，我是您的私人管家

从今天起，我是您专属的智能助手。您可以：

- **叫我任何名字**：说"以后叫我小助手"，我就会记住
- **记住您的一切**：我喜欢喝美式咖啡 → 下次问"我喜欢喝什么"，我会回答"美式咖啡"
- **帮我记待办**：说"提醒我下午3点开会"，我会帮您记住
- **随时聊天**：我24小时在线，随时听候您的吩咐

## 您的数据，只有您能看到

所有对话记录、偏好设置都存储在您的本地设备，不上传云端。您的隐私，由您自己掌控。

## 如何使用

访问 http://localhost:5002 ，开始与您的私人管家对话。

您也可以加入俱乐部，随着使用次数增加，解锁更多功能：

- 青铜（0次）：基础对话
- 白银（100次）：学习进化
- 黄金（500次）：数据导出
- 钻石（1000次）：多管家管理
