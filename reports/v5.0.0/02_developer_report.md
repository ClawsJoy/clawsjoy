# ClawsJoy v5.0.0 - 开发者文档

## 架构概览

ClawsJoy 是一个配置驱动的多租户 AI Agent 操作系统。
┌─────────────────────────────────────────────────────────────┐
│ Agent 注册中心 (17个) │
├─────────────────────────────────────────────────────────────┤
│ 私人管家 | 决策引擎 | 分析师 | 编排器 | 会议系统 | 协作系统 │
├─────────────────────────────────────────────────────────────┤
│ 统一配置层 (unified_config) │
├─────────────────────────────────────────────────────────────┤
│ 6/6 闭环大脑 │
├─────────────────────────────────────────────────────────────┤
│ DO 执行层 (135技能) │
└─────────────────────────────────────────────────────────────┘

## 核心设计原则

1. **配置驱动**：所有行为通过 YAML 配置，无需修改代码
2. **代理模式**：单数据源，强一致性
3. **Agent 注册中心**：动态注册，热插拔
4. **向量记忆**：L0-L4 分层记忆
5. **闭环大脑**：6/6 自学习循环

## 技术栈

| 组件 | 技术 |
|------|------|
| 后端 | Python 3.13 + Flask |
| WSGI | gunicorn + gevent |
| 向量库 | ChromaDB |
| LLM | Ollama (qwen2.5:7b/3b) |
| 配置 | YAML |
| 部署 | Docker / systemd |

```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
./start_prod.sh

# 测试
curl http://localhost:5002/api/health
API 端点
端点	用途
/api/butler/chat	私人管家对话
/api/butler/club/*	俱乐部管理
/api/meeting/*	会议系统
/api/closed_loop/*	闭环控制
/api/skills/*	技能执行
贡献指南

新增路由：修改 config/routes.yaml，在 route_handlers.py 实现

详细文档见 docs/ 目录。
