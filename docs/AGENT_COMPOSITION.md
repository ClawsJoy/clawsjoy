## 2. Agent 组合规则

### 规则1: 技能声明
每个技能必须在 SKILL.md 中声明：
- `use_when`: 什么场景使用
- `not_for`: 什么场景不使用
- `dependencies`: 依赖的其他技能

### 规则2: 组合指引
LLM 通过以下方式选择组合：
1. 解析用户意图
2. 匹配 `use_when` 规则
3. 检查依赖关系
4. 生成执行计划

### 规则3: 执行验证
- 检查前置条件
- 验证输出格式
- 处理错误回滚
