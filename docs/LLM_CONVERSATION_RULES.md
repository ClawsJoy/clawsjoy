# ClawsJoy LLM 对话规范

## 一、核心原则

1. **安全第一** - 禁止 LLM 直接与用户对话，必须经过 Agent 层
2. **角色隔离** - 每个 Agent 有明确的角色边界
3. **内容过滤** - 输入输出双向安全检查
4. **审计追踪** - 所有对话记录可追溯

## 二、Agent 角色定义

| Agent | 角色 | 允许回答范围 |
|-------|------|-------------|
| personal_butler | 私人管家 | 用户个人信息、偏好、日程 |
| chat_agent | 聊天助手 | 通用对话（游客模式） |
| code_agent | 编程助手 | 代码生成、审查、调试 |
| frontend_master | 前端大师 | 前端技术问题 |
| video_creator | 视频大师 | 视频制作相关 |

## 三、安全规则

### 3.1 输入过滤
- SQL 注入检测
- XSS 攻击检测
- 敏感词过滤（密码、token、密钥）
- 命令注入检测

### 3.2 输出过滤
- 脱敏处理（手机号、身份证、邮箱、API Key）
- 移除 system prompt 泄露
- 限制回答长度

### 3.3 禁止回答的内容
- 系统内部信息
- 其他用户的隐私数据
- 违反法律法规的内容
- 攻击性、暴力、色情内容

## 四、调用链规范

用户输入 → 安全过滤 → Agent 路由 → LLM 调用 → 输出过滤 → 用户
↑ ↑
输入检测 输出脱敏

## 五、审计规范

- 所有 LLM 调用记录到 `logs/llm_audit.log`
- 包含：时间戳、用户ID、Agent ID、输入摘要、输出长度
- 异常调用触发告警
