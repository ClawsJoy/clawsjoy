## 一、项目概述

ClawsJoy 4.0 是一个企业级智能化内容运营平台，已完成从配置驱动到多 Agent 协作的全面升级，核心定位为**用户的数字分身和私人管家**。

### 核心成就
- ✅ 多 Agent 协作架构（决策/聊天/执行/采集/安全）
- ✅ 用户数据完全隔离，加密存储
- ✅ HTTPS + JWT 安全通信
- ✅ 19种敏感信息脱敏规则
- ✅ 配置驱动，无硬编码
- ✅ 异步文件夹交割通信
