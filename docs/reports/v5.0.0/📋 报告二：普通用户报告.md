ClawsJoy v5.0.0 阶段性工作报告
📋 报告二：普通用户报告
一、ClawsJoy 是什么？
ClawsJoy 是一个智能体AI操作系统，让您拥有专属的私人管家，可以帮您：

管理日程和提醒

生成代码和文档

创建自动化工作流

使用 135+ 原子技能

二、快速开始
2.1 注册账号
打开 ClawsJoy 客户端

点击 商店 → 选择订阅方案

填写用户名和密码

点击注册

2.2 登录使用
点击 已有账号？点击登录

输入用户名和密码

登录后自动进入工作空间

三、核心功能
3.1 私人管家
点击左侧菜单 私人管家

可以文字输入或语音输入

小管会记住您的偏好和习惯

3.2 工作流编辑器
点击 工作流编辑器

从左侧拖拽节点到画布

连接节点创建流程

点击 执行 运行工作流

3.3 代码审核
点击 代码审核

粘贴代码

点击 分析代码 获得审查结果

点击 自动修复 尝试修复问题

3.4 技能库
点击 技能库

浏览 135+ 原子技能

点击技能查看详情

四、常见问题
Q: 语音输入不工作？
A: 请使用 Chrome 浏览器打开管家页面，或在 Electron 中检查麦克风权限。

Q: 如何切换账号？
A: 点击右上角 退出，返回商店重新登录。

Q: 工作流如何保存？
A: 点击工具栏 保存，输入工作流名称。

Q: 代码审核支持哪些语言？
A: 支持 Python、JavaScript、TypeScript、Java、Go。
