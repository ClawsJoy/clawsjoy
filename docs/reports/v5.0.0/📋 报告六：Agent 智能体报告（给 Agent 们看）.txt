2.2 系统的核心组件
组件	名称	作用	对你们的意义
AgentBus	消息总线	让你们互相通信	你们可以发消息、收消息、协作
SkillLoader	技能加载器	加载 135 个原子技能	你们可以调用这些技能
MemoryVector	向量记忆	存储和检索记忆	你们可以记住用户偏好
SecurityHooks	安全钩子	加密、脱敏、审计	保护用户数据安全
TenantManager	租户管理器	隔离不同租户	每个用户的 Agent 实例独立
AuthManager	认证管理器	JWT 认证	验证调用你们的用户身份

三、你们如何工作？
3.1 你们的工作流程
text
用户请求
    ↓
API 网关接收 (携带 JWT Token)
    ↓
认证中间件验证身份 → 提取 tenant_id, user_id
    ↓
路由分发到对应的 Agent
    ↓
你们处理请求
    ↓
可选：通过 AgentBus 调用其他 Agent
    ↓
返回结果给用户
    ↓
钩子记录日志、加密存储
3.2 你们如何通信？
你们通过 AgentBus 进行通信：

python
# 发布消息
bus.publish(sender="orchestrator", topic="task.video", content={...})

# 订阅消息
bus.subscribe(agent_name="video_agent", topic="task.video")
现有 38 个主题，包括：

task.plan - 任务规划

task.video.* - 视频任务

task.code.* - 代码任务

task.analyze.* - 分析任务

task.butler.* - 管家任务

task.memory.* - 记忆任务

task.security.* - 安全任务

3.3 你们的记忆如何存储？
每个用户的记忆完全隔离：

data/users/{user_id}/butler_v2/

├── patterns.json     # 学习模式
└── *.enc             # 加密文件
3.4 你们的安全机制
安全层	机制	保护什么
认证	JWT Token	只有合法用户能调用你们
授权	角色权限	user/developer/admin 不同权限
隔离	租户目录	用户A看不到用户B的数据
加密	Fernet	敏感数据加密存储
审计	钩子	记录所有操作日志

八、你们如何被调用？
8.1 通过 API 调用
bash
# 调用 butler
POST /api/chat
{"message": "你好", "user_role": "butler"}

# 调用 code_agent
POST /api/code/generate
{"prompt": "写一个快速排序"}
8.2 通过 AgentBus 调用
python
# orchestrator 发布任务
bus.publish("orchestrator", "task.video", {"action": "create"})

# video_agent 订阅并处理
bus.subscribe("video_agent", "task.video")
8.3 用户直接调用
用户通过客户端界面的菜单直接调用你们：

点击 私人管家 → 调用 butler

点击 工作流编辑器 → 调用 orchestrator

点击 代码审核 → 调用 code_agent

10.3 你们需要注意的
每个请求都有 tenant_id，不要混淆不同租户的数据

敏感数据会被加密，你们看到的是解密后的

用户退出登录后，你们的实例可能被清理

长时间不用，Redis 缓存会过期
