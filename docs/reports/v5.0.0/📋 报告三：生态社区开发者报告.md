一、开发者平台概述
ClawsJoy 为开发者提供完整的创业平台，包括：

二、开发技能
2.1 技能格式
python
class MySkill:
    """技能描述"""
    
    def execute(self, params):
        # 业务逻辑
        return {
            "success": True,
            "result": "处理结果"
        }

skill = MySkill()
2.2 技能注册
技能文件放在 skills/{category}/ 目录下，系统自动加载。

2.3 技能分类
分类	说明	示例
math	数学计算	sqrt, add, multiply
video	视频制作	manju_maker, add_subtitles
finance	投资理财	get_stock, exchange_rate
health	健康监测	heart_rate, temperature
education	儿童教育	learn_english, math_quiz
三、API 接口
3.1 认证接口
bash
# 注册
POST /api/auth/register
{"username": "xxx", "password": "xxx", "role": "user"}

# 登录
POST /api/auth/login
{"username": "xxx", "password": "xxx"}
3.2 技能接口
bash
# 获取技能列表
GET /api/skills

# 执行技能
POST /api/skills/execute
{"skill": "skill_name", "params": {...}}
3.3 代码生成接口
bash
# 生成代码
POST /api/code/generate
{"prompt": "写一个快速排序"}

# 代码审查
POST /api/code/review
{"code": "def add(a,b): return a+b"}
