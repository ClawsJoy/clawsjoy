## 一、产品介绍

ClawsJoy 是您的**智能私人管家**，可以记住您的偏好，帮助处理日常任务。

### 核心功能

| 功能 | 说明 |
|------|------|
| 💬 智能对话 | 自然语言交流，记住偏好 |
| 🔧 AI工具集 | 116个技能 |
| 📚 记忆系统 | 记住习惯，越用越懂您 |
| 🔒 隐私保护 | 数据本地加密 |

## 二、快速开始

### 安装
1. 双击 `ClawsJoy Setup 4.0.0.exe`
2. 按向导完成安装
3. 从桌面快捷方式启动

### 示例对话
用户: 我叫张三，喜欢简洁回答
Agent: 你好，张三！我会简洁回答

用户: 我叫什么？
Agent: 您叫张三

## 三、功能详解

### 私人管家
- 记住名字和偏好
- 记录待办事项
- 主动提醒

### AI工具集
- 数学计算：加减乘除、平方根
- 文本处理：大小写转换、反转
- 图像处理：去背景、生成图像
- 视频制作：合成、字幕

## 四、常见问题

**Q: 后端连接失败？**
A: 确保 WSL 后端已启动

**Q: 数据会丢失吗？**
A: 本地加密存储，定期自动备份
