# 技能验证架构

## 1. 技能验证三层模型
┌─────────────────────────────────────────────────────────────────┐
│ 技能验证架构 │
├─────────────────────────────────────────────────────────────────┤
│ │
│ Layer 1: 静态验证 │
│ ├── SKILL.md 元数据完整性 │
│ ├── scripts/main.py 语法检查 │
│ └── execute 函数签名验证 │
│ │
│ Layer 2: 动态验证 │
│ ├── 参数校验 │
│ ├── 依赖检查 │
│ └── 环境验证 │
│ │
│ Layer 3: 运行验证 │
│ ├── 功能测试 │
│ ├── 性能测试 │
│ └── 安全测试 │
│ │
└─────────────────────────────────────────────────────────────────┘
## 2. 技能验证流程

1. **注册时验证** - 语法、元数据
2. **调用时验证** - 参数、依赖
3. **运行时验证** - 执行结果、错误处理
